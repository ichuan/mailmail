# 开发指南

## 启动开发环境

### 完整 Tauri 桌面应用（推荐）

```bash
npm run tauri:dev
# 等价于: node_modules\.bin\tauri dev
```

此命令会自动：
1. 启动 Vite 开发服务器（`npm run dev`），监听 http://localhost:5173
2. 编译 Rust 后端
3. 打开带热重载的桌面窗口

> **注意**：`npx @tauri-apps/cli dev` 在某些环境下会报错 `cb.apply is not a function`（全局 npm CLI 问题）。
> 始终使用 `npm run tauri:dev` 或直接调用 `node_modules\.bin\tauri dev`。

### 仅启动前端（调试 UI 时用）

```bash
npm run dev
# 浏览器打开 http://localhost:5173
```

Tauri 命令（`invoke`）在浏览器中不可用，仅做 UI 布局调试用。

## 运行测试

### 前端测试（Vitest）

```bash
npm test          # 单次运行
npm run test:watch  # 监听模式
```

测试文件位于 `src/test/`。当前基线：21 个测试文件，131 项测试通过。

### Rust 后端测试

```bash
cd src-tauri
cargo test
```

测试内嵌在各模块的 `#[cfg(test)]` 块中（`db.rs`、`imap.rs`、`models.rs`、`plugin_host.rs`、`smtp.rs`）。当前基线：51 项测试通过。

### 稳定性验证

```bash
npm test
npm run build
cd src-tauri
cargo test
cargo check
```

长运行相关手动验证：

| 场景 | 期望 |
|------|------|
| 断网 2-5 分钟后恢复 | IMAP IDLE 指数退避重连，恢复后继续收信 |
| SMTP 服务器临时不可达 | 20s timeout 后最多重试 2 次，UI 不显示假成功 |
| 删除大型邮箱邮件 | `UID STORE` / `EXPUNGE` 不无限挂起 |
| HTML 邮件连续切换 100 次 | iframe click listener 不线性增长 |
| 10MB+ 附件邮件 | 超限附件跳过存储，应用不崩溃 |
| Toast 错误风暴 | 页面最多显示 5 条 Toast |

## 构建生产包

```bash
npm run tauri:dev   # 先确认 dev 正常
npm run build       # 仅编译前端资源（tsc + vite）
node_modules\.bin\tauri build   # 完整打包，输出在 src-tauri/target/release/
```

## 常见问题

| 问题 | 排查方向 |
|------|----------|
| `cargo check` 失败 | 检查 `src-tauri/src/` 下编译错误；Windows 需确认 MSVC 工具链 |
| IMAP 连接超时 | 检查账号 IMAP 服务器地址、端口、是否开启应用专用密码 |
| 前端 invoke 无响应 | 确认是在 Tauri 桌面窗口中运行，不是浏览器 |
| SQLite locked 错误 | 确认没有多个 tauri dev 进程同时运行；当前 SQLite 已启用 WAL 与 busy_timeout |
| SMTP 发送失败 | 区分认证/地址等永久错误与 timeout/connection 等 transient 错误；transient 会自动有限重试 |
| 附件缺失 | 检查日志是否出现附件超过 10MB 或单邮件超过 50MB 的跳过记录 |
