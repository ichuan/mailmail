# 开发指南

## 启动开发环境

### 完整 Tauri 桌面应用（推荐）

```bash
npm run tauri:dev
# 等价于: node_modules\.bin\tauri dev
```

此命令会自动：
1. 启动 Vite 开发服务器（`npm run dev`），监听 http://localhost:5173
2. 编译 Rust 后端
3. 打开带热重载的桌面窗口

> **注意**：`npx @tauri-apps/cli dev` 在某些环境下会报错 `cb.apply is not a function`（全局 npm CLI 问题）。
> 始终使用 `npm run tauri:dev` 或直接调用 `node_modules\.bin\tauri dev`。

### 仅启动前端（调试 UI 时用）

```bash
npm run dev
# 浏览器打开 http://localhost:5173
```

Tauri 命令（`invoke`）在浏览器中不可用，仅做 UI 布局调试用。

## 运行测试

### 前端测试（Vitest）

```bash
npm test          # 单次运行
npm run test:watch  # 监听模式
```

测试文件位于 `src/test/`。

### Rust 后端测试

```bash
cd src-tauri
cargo test
```

测试内嵌在各模块的 `#[cfg(test)]` 块中（`db.rs`、`models.rs`）。

## 构建生产包

```bash
npm run tauri:dev   # 先确认 dev 正常
npm run build       # 仅编译前端资源（tsc + vite）
node_modules\.bin\tauri build   # 完整打包，输出在 src-tauri/target/release/
```

## 项目结构速查

```
src/                        React + TypeScript 前端
  App.tsx                   主三栏布局、同步逻辑、事件监听
  store.ts                  Zustand 全局状态
  ComposeView.tsx            写信/回复/转发
  AddAccountView.tsx         添加账号表单
  SettingsView.tsx           设置页
  test/                     Vitest 测试（71 项）

  core/                     插件系统基础设施
    event-bus.ts            类型安全的发布/订阅（17 种事件类型）
    slot-registry.tsx       UI 槽位注册 + <Slot> React 组件
    plugin-manager.ts       插件加载/卸载/生命周期管理
    permissions.ts          权限声明 + 运行时检查
    plugin-api.ts           PluginAPI / PluginContext / Disposable 类型定义

  plugins/                  内置插件
    theme-switcher/         明/暗主题切换
    image-toggle/           显示/隐藏图片开关
    signature/              邮件签名（完整 CRUD）

src-tauri/src/              Rust 后端
  main.rs                   Tauri 命令注册入口
  db.rs                     SQLite 持久层（sqlx）
  imap.rs                   IMAP 收信 + IDLE + RFC 2047 解码
  smtp.rs                   SMTP 发信逻辑（lettre）
  models.rs                 共用数据结构
```

## 常见问题

| 问题 | 排查方向 |
|------|----------|
| `cargo check` 失败 | 检查 `src-tauri/src/` 下编译错误；Windows 需确认 MSVC 工具链 |
| IMAP 连接超时 | 检查账号 IMAP 服务器地址、端口、是否开启应用专用密码 |
| 前端 invoke 无响应 | 确认是在 Tauri 桌面窗口中运行，不是浏览器 |
| SQLite locked 错误 | 同一时间只允许一个 tauri dev 进程访问 DB |
