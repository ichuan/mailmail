# 开发计划与状态

> 最后更新：2026-05
> 当前状态：所有核心功能 + 插件架构 Phase 1-4 已完成，71 项前端测试通过。

## 已完成里程碑

### 核心功能（全部完成）

- 账号 CRUD（IMAP/SMTP 配置持久化）
- 多文件夹 IMAP 同步（inbox / sent / trash）
- 邮件本地缓存：SQLite `upsert_email` + 启动时先读缓存再后台刷新
- 删除邮件（服务器端 `STORE \Deleted + EXPUNGE`，DB + Store 同步，带确认对话框）
- SMTP 发件（含 Reply / Forward，RFC 引用格式）
- 本地全文搜索（SQLite LIKE，300ms debounce）
- 设置持久化（syncLimitDays、showImages）
- 附件支持（multipart 解析、`get_attachments` / `save_attachment` 命令、阅读面板下载 UI）
- IMAP IDLE 实时推送（Rust 后台 task，`mail:new` 事件推送前端）
- Windows Keychain（`keyring` v3 `windows-native`，密码不再明文存 SQLite）
- RFC 2047 头部解码（Q/B encoding，GBK/Big5/ISO 多字节字符集支持）

### Bug Fix Sprint（完成）

| Bug | 根因 | 修复 |
|-----|------|------|
| 链接点击劫持整个 WebView | `<a>` 在 `dangerouslySetInnerHTML` 内直接导航 | `tauri-plugin-shell` `open()` 在系统浏览器打开 |
| 时间戳只显示 `h:mm a` | 硬编码格式 | `smartFormatTime`：<1h→"32m"，<24h→"3h"，同年→"Mar 24"，更早→"2025/1/2" |
| "to me" 硬编码 | `To:` header 未解析 | 全管道修复：imap.rs → `recipient` 字段 → DB → Store → UI |
| HTML 邮件行间距过大 | `whitespace-pre-wrap` 应用于 HTML 容器 | 移除容器级样式，仅在纯文本分支应用 |
| HTML 邮件 CSS 被剥除 | `ammonia::clean()` 默认不保留 `style` | 改用 `Builder` 允许 `style` 属性 |
| 图片不显示 | ammonia 默认剥除 `<img>` | `Builder` 加白名单；JS 层按 `showImages` 开关剥除 |

### UI 增强 Sprint（完成）

## 下一步开发优先级

### P1：安全增强

| 项目 | 说明 | 难度 |
|------|------|------|
| `<iframe sandbox>` HTML 渲染 | ammonia 已净化但无沙箱，XSS 风险仍存在；用 `<iframe sandbox="allow-same-origin">` 渲染 `bodyHtml` | 中 |
| ammonia CSS url() 过滤 | `style` 属性中的 `url()` 值可用于 CSS tracking pixel；`Builder` 加正则过滤 | 低 |

### P2：体验提升

| 项目 | 说明 | 难度 |
|------|------|------|
| 解析 From 头显示名 | `sender` 字段当前为原始 `Display Name <email>` 字符串；需分离显示名与邮箱地址 | 低 |
| 虚拟滚动 | 大邮箱（1000+ 封）当前使用全量 DOM 列表，会出现卡顿 | 中 |
| Markdown 写信编辑器 | ComposeView 富文本选项（`@mm/markdown-compose` 插件形式） | 中 |

### P3：通知与后台

| 项目 | 说明 | 难度 |
|------|------|------|
| 桌面通知插件 | IDLE 已推送 `mail:new`；接入 `tauri-plugin-notification` 实现系统托盘通知 | 低 |
| Reply All 收件人去重 | Reply All 收件人目前基于原始 From header，需解析后去重 | 低 |

### P4：高级功能（排期靠后）

- OAuth2 / 应用专用密码自动检测
- 邮件标签/分类系统（`@mm/labels` 插件）
- 联系人自动补全
- PGP 加密签名（`@mm/pgp` 插件，Rust 后端）
